Daily planner against procrastination: plan as a text list, a timer per to-do, fixed breaks, a motivating coach and a progress history.

== Description ==

Write your day as a text list – every line becomes a tappable to-do with a timer. Between to-dos there is a break with a fixed end. A coach motivates you, and the history shows how much more you get done over the weeks.

* Plan as text, one line per to-do, starting with "- "
* Tap to start or pause the timer; the tick ticks a to-do off
* Break between to-dos with countdown and sound
* Saved as text: `- Walk {08:30|09:05|00:35}` (start, end, duration)
* Carry open to-dos over from yesterday
* History of the last 14 days compared with the week before
* Every user sees only their own data

Use the "Fokus-Log" menu in the admin, or put the block "Fokus-Log" or the shortcode `[bw_fokus_log]` on a page.

== Installation ==

1. Upload the ZIP under Plugins > Add New > Upload Plugin and activate it.
2. Open "Fokus-Log" in the admin menu.
